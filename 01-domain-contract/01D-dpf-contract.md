# DPF-контракт домена: нотация ДРАКОН

> Оформлено по паттерну FPF `E.4.DPF`.

---

## Предмет рамки

Формальные правила визуального языка ДРАКОН и перевод уже табличного метода (`E.18`) в схему по этим правилам.

---

## Стадия авторства

**Текущая стадия:** первичный проход (seed). Собрано за одну сессию 2026-07-31 - как перенос материала, собранного пилотом 2026-07-27.

| Компонент рамки | Состояние | Комментарий |
|---|---|---|
| Граница домена (`01A`) | заполнена | Наследует границу, уже проведённую в исходном `drakon-knowledge-base.md` |
| Различения (`01B`) | 5, все seed | Взяты из первоисточника, не изобретены |
| Метод (`03`) | 1, draft | Прямое структурное соответствие таблице из исходного файла |
| Роль (`02`) | 1, draft | Дизайнер-конструктор схемы, с явной ссылкой на предметное воплощение (`FE.R.001`) |
| Ошибки (`05`) | 4, draft | Именованные в первоисточнике запреты, не произвольные |
| Источники (`06`) | 2 первичных + 1 инструментальный + отклонённые материалы | Полнее обычного стартового прохода - материал уже был собран заранее |
| Рабочие продукты (`04`) | пусто | Не заполнялись в этой сессии |

---

## Что рамка обещает

- Дать проверяемые правила построения схемы, прослеживаемые до первоисточника
- Отделить правило языка (неизменное) от возможности инструмента (меняется)
- Дать метод перевода уже готового табличного описания в схему, без переизобретения логики
- Явно решить для каждого применения, схема - источник истины или рендер

## Чего рамка не обещает

- Обучения интерфейсу конкретного редактора
- Логики предметных методов - она в предметном Pack
- Готового решения «нужна ли кодогенерация здесь» - это решается по различению `DRK.D.003` в каждом конкретном случае

| Переход | Условие |

| seed → проработанная рамка | Различения проходят чек-лист mature-lite; появляются карточки рабочих продуктов |
| Расширение source-базы | Прочтение оставшихся не разобранных глав первоисточников |
| Второе предметное применение | Появление ДРАКОН-схемы для метода за пределами `FE.M.001` (кандидат - методы инженерии турбозажигалки с высокой ценой ошибки) |
