## Ядро домена в одном абзаце

ДРАКОН - формальный визуальный язык с жёсткими правилами (шампур, силуэт, запреты), спроектированный под задачу «ошибка недопустима». В этой системе он применяется как альтернативный визуальный рендер метода, уже структурированного таблицей позиций (`E.18`) в предметном Pack - не как способ придумать логику метода заново, а как способ сделать её панорамно читаемой и, где оправдано, исполняемой напрямую через кодогенерацию.

## Различения и где они срабатывают

| Различение | Гвардит |
|---|---|
| `DRK.D.001` примитив ≠ силуэт | Выбор формы схемы (метод, поз. 2) |
| `DRK.D.002` главный маршрут ≠ побочный | Упорядочивание маршрутов (поз. 4) |
| `DRK.D.003` источник истины ≠ рендер | Решение о генерации кода (поз. 8) - ключевое для каждого нового предметного применения |
| `DRK.D.004` шампур-блок ≠ произвольная линия | Проверка шампура (поз. 5) |
| `DRK.D.005` икона «Вставка» ≠ процедура | Декомпозиция (поз. 7) |

## Ошибки по позициям метода

| Позиция | Ошибка |
|---|---|
| 1 Три царских вопроса | `DRK.FM.004` схема без «шапки» силуэта |
| 4 Упорядочивание маршрутов | `DRK.FM.003` побочный маршрут левее главного |
| 5-6 Проверка шампура и запретов | `DRK.FM.001` сиамские близнецы, `DRK.FM.002` пересечение или обрыв |

| Pack | Направление | Что передаётся |

| `PACK-furniture-engineering` | вниз (потребитель) | Метод `FE.M.001` - формульные позиции 1, 2a, 3a, 4, 6 рендерятся через ДРАКОН по решению архитектурной оценки 2026-07-27; позиция 8 (гейт Технолога) намеренно вне автоматизации |
