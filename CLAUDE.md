# PACK-drakon-notation

Source-of-truth для домена: нотация ДРАКОН.
Структура: SPF/pack-template. Upstream: FPF, SPF.

При работе с этим Pack: читать `00-pack-manifest.md` для навигации, `07-map/DRK-map.md` для быстрого входа.

Короткий код сущностей: `DRK` (например `DRK.D.001`, `DRK.M.001`, `DRK.FM.004`).

## Что помнить при наполнении

- **Домен обслуживает несколько предметных Pack.** Метод предметного домена живёт там; ДРАКОН-рендер этого метода - принцип здесь, применение - в предметном Pack.
- Первоисточник - книга и рукопись Паронджанова (см. `DS-strategy/inbox/WP-7/drakon-knowledge-base.md` для деталей доступа). Не пересказывать язык по памяти - сверяться с первоисточником.
- Не смешивать правило языка (неизменное) с возможностью конкретного инструмента (меняется) - см. `DRK.D.003`.
- Пока `name_status: provisional` - имя не закреплено, ждёт личного подтверждения пилота.
